# DivyaSeva (दिव्यसेवा) — Divine Puja Services

A world-class Indian spiritual services platform for booking authentic Vedic pujas, connecting with experienced pandits, and purchasing sacred products.

## Features

- **10+ Puja Services** — Griha Pravesh, Rudra Abhishek, Mahamrityunjay Jaap, Satyanarayan Katha, Mangal Dosh Nivaran, Kaal Sarp Dosh, and more
- **Expert Pandits** — Verified Vedic scholars with 15-35 years of experience
- **Sacred Store** — Rudraksha, Yantras, Puja Kits, Stress Relief products
- **Multi-Language** — English, Hindi (हिन्दी), Kannada (ಕನ್ನಡ), Tamil (தமிழ்), Telugu (తెలుగు)
- **Booking System** — 4-step booking with date, time, package selection
- **Payment Gateway** — Razorpay integration (UPI, Cards, Net Banking, Wallets)
- **Responsive Design** — Works on all devices

## Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion (animations)
- Lucide React (icons)
- Razorpay (payments)

## Getting Started

```bash
cd divyaseva
npm install
npm run dev
```

Open http://localhost:3000

## Environment Variables

Copy `.env.example` to `.env.local` and add your Razorpay keys:

```bash
cp divyaseva/.env.example divyaseva/.env.local
```
